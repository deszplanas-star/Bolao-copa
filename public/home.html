► A construção

Stack · Banco · API · Segurança
Cinco semanas até o lançamento
01 Front
Next.js 14 · React · Tailwind · Framer Motion · shadcn/ui · React Query SSR para landing, client para apostas, optimistic UI em todo input.
02 Back
Node 20 · Route Handlers do Next · Zod · Prisma · Resend Sem servidor para gerenciar, validação tipada de ponta a ponta.
03 Banco & Auth
PostgreSQL gerenciado pelo Supabase · Auth via Google OAuth · RLS por tabela · Realtime via WebSocket Defesa em profundidade até no SQL.
04 Infra
Vercel · Supabase · Cron diário 23:59 · GitHub Actions · Sentry · Posthog Tier gratuito comporta milhares de apostadores.

Modelo de dados

8 tabelas · PostgreSQL · RLS

users

id, google_id, name, email, avatar_url, role, created_at

teams

id, code, name, flag_emoji, group_id

groups

id, code, name, order

matches

id, group_id, home_team_id, away_team_id, kickoff_at, home_score, away_score, status

predictions

id, user_id, match_id, home_score, away_score, points — UNIQUE(user_id, match_id)

payments

id, user_id, amount_cents, status, user_confirmed_at, approved_at, approved_by, denied_reason

rankings

view · user_id, total_points, exact_hits, partial_hits, position, last_movement

admin_logs

id, admin_id, action, target_type, target_id, payload, ip, created_at — append-only

API REST

Route Handlers · Zod · JWT
GET/api/me
Usuário logado e status do pagamento
GET/api/groups
Grupos com seleções e classificação atual
GET/api/matches
Jogos da fase de grupos com meu palpite
POST/api/predictions
Upsert de palpite — bloqueia após cutoff
POST/api/payments/confirm
Usuário confirma Pix — notifica admin
GET/api/ranking
Ranking geral, paginado
PUT/api/admin/payments/:id/approve
Aprova Pix, dispara e-mail
PUT/api/admin/matches/:id/result
Insere placar oficial, recalcula pontos

Segurança

6 camadas · defesa em profundidade
01 / Auth
JWT + RLS

Sessão Supabase com refresh. Mesmo bypass da API respeita policies.

02 / Input
Validação Zod

Toda entrada de API validada antes de tocar no banco.

03 / Tempo
Cutoff server-side

Servidor checa o relógio. Manipular o cliente é inútil.

04 / Tráfego
Rate limit

10 req/s no palpite, 3 req/s no resto. Vercel KV.

05 / Ranking
Pagamento gated

Só pagamento aprovado entra. Sem aprovação, palpite é fantasma.

06 / Auditoria
Logs append-only

Toda ação admin registrada com IP. Sem UPDATE/DELETE.
